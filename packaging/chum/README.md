# Publishing to SailfishOS:Chum

The OBS package is built from a tag of this repository. The spec lives in
`rpm/harbour-ncpasswords.spec` and the source archive is generated by the
`tar_git` source service.

1. Push the repository to GitHub and create a release tag (`v1.0.0`).
2. In the [Sailfish OS OBS](https://build.sailfishos.org/), open your home
   project and create a package named `harbour-ncpasswords`.
3. Add [`_service`](_service) to the package (update the URL and `revision`
   if needed) and let OBS fetch the sources.
4. Add build targets for the Sailfish OS releases you want to support. The
   package needs `libsodium-devel`, which is available from
   `sailfishos:chum`; add that repository to the project metadata if the
   target does not already provide it.
5. Verify that all targets build. Then use **Submit Package** with
   `sailfishos:chum:testing` as the target.
6. After the initial submission is accepted, you become the maintainer of the
   package and can promote it to `sailfishos:chum`.

Chum builds a fixed revision on purpose. Bump `Version` in the spec, create a
new tag and update the `revision` in `_service` for each release.

The Chum-specific metadata (title, categories, icon and links) is embedded at
the end of the `%description` section of the spec, as required by
<https://github.com/sailfishos-chum/main/blob/main/Metadata.md>.
