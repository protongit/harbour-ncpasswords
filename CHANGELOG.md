# Changelog

## 1.0.0 - 2026-11-10

First public release.

- Native Sailfish OS client for the Nextcloud Passwords app
- Nextcloud Login Flow v2 (including two-factor authentication) and manual
  app-password login
- Client-side encryption (`CSEv1r1`) with the vault master password
- Password list, search, folders, tags, favourites, hidden entries, trash and
  custom fields
- TOTP codes on the entry page and on the cover
- Password generator with four strength presets
- PIN lock with Argon2id, automatic locking and clipboard clearing
- App password stored in Sailfish Secrets when available
- English and Spanish UI with a language selector
- Standard Sailfish pull-down menu and folder-first start view
